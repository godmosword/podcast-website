## 場景群演（無獨立定裝）

- 「其他好多的小車車們」— 彩虹廣場點心場景，可用既有車車遠景帶過
- 點心（飯糰、水果、果汁）— 場景道具，非角色

## 新角色視覺要點（對齊黏土定裝家族）

### 消毒車噴噴

- **車身：** 奶油白小貨車，亮晶晶高光（呼應「車身亮晶晶的」）
- **特徵：** 後方大型圓柱噴霧桶、橘色警示條、噴嘴細霧
- **表情：** 驕傲自信（故事前半），後段可畫略害羞
- **區隔：** 不同於鈴鈴（綠色清潔車＋刷毛）、安安（紅十字救護車）

### 髒髒小怪獸

- **造型：** 3–5 顆灰黑絨毛小圓球，調皮笑臉、短刺
- **無輪子／無車體**
- **出沒：** 輪胎縫、鏟子旁、門把、鼻屎小手（字幕 183–235s）

## illustrate 接線

```bash
npm run illustrate -- ep-15 --segment-only   # 切場景時會讀名冊
npm run illustrate -- ep-15                  # 生圖（需 OPENAI_API_KEY）
```

名冊已設 `firstSeen: ep-15`（噴噴、小怪獸）或 `alsoIn: ["ep-15"]`（回歸角色）。
