# 森林小島 Art Direction — 宜蘭林場篇

> 目的：把現有泛用森林島升級成《車車遊樂園》真正的故事場景，但在付費生圖前先鎖定構圖與驗收標準。

## 核心定位

森林小島不是「樹很多的島」，而是 **生活探索 × 宜蘭林場 × 運送任務** 的故事入口。

世界層要在 1 秒內讓人讀到三件事：

1. 這是森林／林場。
2. 有一台黃色大卡車正在工作。
3. 這裡跟木頭運送、蒸汽火車有關。

## Golden composition

- 延續 `car-park.png` 的 3/4 高視角、柔和漫射光、霧面黏土材質。
- 島仍是奶油沙岸＋柔綠草頂，外框比例與現有 forest tile 契約一致。
- 中央主角：**大黃卡車**，視覺尺寸約佔島內容高度 28–34%。
- 大黃後方車斗為長型、橫式欄杆，不用直立柱式木材架。
- 車斗上只放 **三根粗木頭**，世界層避免六根造成視覺雜訊；故事內容仍可講六根。
- 左後：少量林場木材堆疊，2–3 根即可。
- 右後：**8 號蒸汽火車意象**，只露車頭／煙囪與短鐵軌，不搶大黃主角。
- 前景：一小段泥土／木屑運輸路，讓大黃朝島內斜前方行駛。
- 樹木 4–6 棵，保留負空間，不做滿版森林。

## 視覺層級

1. 大黃卡車
2. 三根大木頭
3. 森林／林場地貌
4. 8 號蒸汽火車
5. 小型細節（木樁、花草、路牌）

任何單一背景物件都不得比大黃更醒目。

## 角色 Canon

### 大黃卡車

- 黃色黏土大卡車。
- 高駕駛座、大黑輪胎、長車斗。
- 後車斗為橫式欄杆造型。
- 表情親切、微笑，不做過度擬人肢體。
- 輪子維持 4 個清楚可讀。

### 8 號蒸汽火車

- 黑色蒸汽車頭、大煙囪。
- 白色蒸氣可以一小朵，不能形成大煙霧遮住島。
- 只作故事世界提示，不做第二主角。

## 不要出現

- 文字、英文字、數字牌、Logo。
- 真實照片質感、金屬高光、塑膠玩具高光。
- 超過三根載運木頭。
- 大型建築、摩天輪、城市道路。
- 直立木材柱式車斗。
- 過多小動物或角色。
- 高飽和螢光綠森林。

## World-layer acceptance

在 264×260 CSS stage 尺寸下檢查：

- 100% 尺寸能辨識「黃卡車」。
- 75% 尺寸仍能辨識三根木頭。
- 50% 尺寸仍讀得到森林島，不會變成一團綠色。
- 與 `car-park.png` 並排時，相機、光線、黏土粗糙度一致。
- 透明邊緣乾淨，無洋紅殘邊。
- 沙岸底中心仍對齊既有 `anchorUV: [0.5, 0.84]`。

## Editorial label

世界層固定使用：

- `05 / FOREST ISLAND`
- `森林小島`
- `LIFE EXPLORATION`

不要把故事標題直接塞進世界層；故事名稱留到 fly-in 後的島內 hotspot／sheet。

## 付費生圖邊界

本文件只鎖定規格，不代表授權執行 `npm run generate:forest-zone`。

實際重新生成 forest island 前，需先明確確認「生成 1 張森林島主圖」。生成後先人工看圖，再決定是否接受或重抽；不自動連抽。
