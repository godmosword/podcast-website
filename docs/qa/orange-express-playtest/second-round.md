# 小橘特快車第二次兒童試玩（減法＋旅程）

狀態：**待試玩**。PR-H1（減法）、H2（風景段與路線條）、H3（沿途事件、任務卡、結算事件章）上線後做。結果決定 PR-H4 要調什麼（見 `docs/plans/2026-11-01-orange-express-journey.md`）。

## 試跑設定

- 目的：看第一次試玩的三個問題有沒有改善——**標誌太複雜、太短、目標不清**。
- 對象：跟第一次同一位孩子最好（約 5 歲）；換人的話記下年齡。單次試跑只找卡點，不推論整個年齡層。
- 裝置：真實 iPhone、Safari、直向。記錄可視畫面尺寸。
- 設定：遊戲設定切成**大司機**（家長切，不讓孩子挑）。音效開著（任務卡和事件提示要念）。
- 網址：[小橘特快車正式站](https://podcast-website-mu.vercel.app/games/orange-express)。試玩前確認正式站已部署含 H3 的 commit，記下 SHA。
- 隱私與同意：先取得監護人同意及孩子同意；不錄音、不錄影、不記姓名或其他可識別資料。孩子可隨時停止。
- **計時**：用手機碼表，從按「開始開車」到結算畫面出現。

## 現場流程

1. 新的 Safari 私密分頁開網址；家長在遊戲設定切大司機。不要代替孩子選難度以外的設定。
2. 只說：「你可以自己玩，想停的時候跟我說。」之後安靜。**不要先解釋這趟要做什麼**（要看任務卡自己說不說得清楚）。
3. 孩子求助或停住約 30 秒：先記下畫面和行為，只給一次中性提示「你可以看看畫面上有哪些地方能按。」不示範。
4. 到結算安靜等 20 秒，記下是否自己按「再開一次」。
5. 試玩後只問三句，記原話：
   - 「這一趟要做什麼？」
   - 「路上你看到什麼？」
   - 「你最記得哪一段？」

## 判讀與 H4 的輸入

只引用觀察到的行為或孩子原話。整理成四類：

- **長度**：一趟幾分鐘（目標約 3 分鐘起）、有沒有中途失去興趣（在哪一段）。→ H4 調風景段長度或段數。
- **目標**：說不說得出要接誰、回家；路線條有沒有被看。→ H4 調任務卡、路線條。
- **事件**：哪幾件做到了、哪幾件提示後不知道要做什麼、哪一種最喜歡。→ H4 調事件難度、提示字、造型。
- **符號**：還有沒有被點名太複雜的東西。→ 再減法。

提出最多三項排序建議，交給 PR-H4。
