# 小橘特快車兒童實玩試跑

狀態：**待現場試玩**。本文件是單一兒童探索性試跑的操作表；以下空白紀錄尚未執行，不代表實測結果。

## 試跑設定

- 目的：觀察孩子能否自然選檔並開始、理解動力／煞車／停車／開門流程，以及結算後是否自發重玩；同步觀察封面、窗外場景和地標有沒有吸引注意。
- 對象：一位約 5 歲孩子。此單次試跑只用來發現卡點，不推論整個年齡層。
- 裝置：真實 iPhone、Safari；使用直向。記錄實際可視畫面尺寸。
- 網址：[小橘特快車正式站](https://podcast-website-mu.vercel.app/games/orange-express)
- 版本前置檢查（2026-11-01）：正式站回應 HTTP 200；GitHub 的 Vercel 部署紀錄確認 `Production` 環境已部署 merge commit [`631e6dd`](https://github.com/godmosword/podcast-website/commit/631e6dd211c728b1733dd1c92aeb2675284b5046)。若試玩前版本已改變，重新確認部署版本並記錄。
- 隱私與同意：先取得監護人同意及孩子同意；不錄音、不錄影、不記姓名或其他可識別資料。孩子可隨時停止。

## 現場流程

1. 在新的 Safari 私密分頁開啟網址，確認標題畫面正常。不要代替孩子選難度或調整遊戲設定。
2. 只說：「你可以自己玩，想停的時候跟我說。」之後保持安靜，讓孩子自然選檔並遊玩。
3. 若孩子求助或停住約 30 秒，先記下當下畫面和行為，再只給一次中性提示：「你可以看看畫面上有哪些地方能按。」記下提示原文及孩子接下來的操作；不示範、不指出特定控制項。
4. 到結算畫面後安靜等 20 秒，記錄孩子是否自行選擇「再開一次」。不要先提重玩。
5. 試玩結束後只問：「你最記得哪一段？」「有哪裡不知道怎麼做？」記錄孩子原話；不追問姓名或其他個人資料。

## 判讀與完成條件

先按四類整理證據：**操作理解、駕駛與停車回饋、重玩動機、場景與地標辨識**。只引用觀察到的行為或孩子原話，不把單一孩子的反應寫成普遍結論。

- 基本操作需成人提示：列為操作引導候選問題，附上卡住的步驟與提示後反應。
- 能完成但沒有自發重玩：記下結算停留行為與孩子試後回答，再評估短任務或重玩目標。
- 很少注意窗外場景：先記下孩子是否提及任何地標，再評估地標辨識度及場景接近／經過的變化。
- 試跑後提出最多三項排序建議，並以觀察證據記錄 PR-G 的建議（繼續、延後或先調整）。不因單一試跑自動核准功能改動。

**完成狀態：** 前置部署已確認；現場兒童試玩與觀察紀錄待完成。完成時補齊上表並寫下最多三項建議。
