# 視覺驗收清單

給會改到孩子看得到的畫面、插畫或著色線稿的改動。開 PR 時把適用的項目抄進描述並勾選；不適用的標「不適用」並寫原因。量得到的項目附上量測或截圖。

風格決策見 [`STYLE-BIBLE.md`](STYLE-BIBLE.md)。生圖成本（每輪一輪、重抽先列幕號）見 `.cursor/rules/podcast-image-cost.mdc`，不在這份清單重寫。

## A. 草圖

- [ ] 主角 1 個（場景頁主要角色在 3 個以內，並與參考圖數量一致）；眼、輪、編號、條紋對過 `public/characters` 定裝照。
- [ ] 圖內文字／數字數量 = 0（小紅賽車的「2」除外）。
- [ ] 塗色頁：雲 ≤2、牙齒上下各 ≤6、四邊留白 ≥8%、輪子沒有被裁切。
- [ ] 一個畫面新物件 ≤4 種；主地標縮到 120px 仍認得。

## B. 上色

- [ ] 色碼都在 [`STYLE-BIBLE.md`](STYLE-BIBLE.md) 或 `app/globals.css` 的 token 裡。不在的話標出來並說明。螢光、純飽和色 = 0。
- [ ] 一般文字對比 ≥4.5:1；大字（≥18.66px 粗體或 24px）≥3:1。附計算值。
- [ ] 狀態不靠單一色相：紅／綠、橘／綠並排的地方有圖示或文字。
- [ ] 光影：單一光源、柔和、低對比、沒有硬投影或反光；接地影短。
- [ ] 與黃金樣本 `public/adventures/zones/car-park.png` 或既有同類資產並排：角度、光、材質、色四項一致。

## C. 細修

- [ ] 塗色線稿：黑白二值（灰階像素 &lt;2%，抗鋸齒除外）、線寬約 8px＠1024、輪廓封閉（油漆桶點任一區不外溢）。
- [ ] 可點元素 min-width／min-height ≥48px（全站最低仍是 44px）；相鄰 gap ≥8px。附量測。窄於 360px 的遊戲抬頭例外見風格聖經，若沿用要寫明。
- [ ] 圓角、字級、間距用 token（沒有新的硬寫色碼、沒有新的斷點）。
- [ ] 動畫只含 transform／opacity；`prefers-reduced-motion: reduce` 時沒有位移動畫；沒有每秒閃超過 3 次。
- [ ] 音效要等使用者手勢才播、gain ≤0.14、單音 ≤0.25s、可靜音；沒有錯誤音。
- [ ] 夜間背景不是 `#000`；文字對比 ≥4.5:1。日夜各一張約 390px 寬的截圖。
- [ ] 鍵盤 Tab 到得了互動元素；`:focus-visible` 看得到 3px 環；圖示有可及名稱。
- [ ] 載入、空、失敗各有畫面。沒有 Game Over 壓力文案。
