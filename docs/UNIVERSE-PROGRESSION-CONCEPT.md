## 1. 給孩子的目標（先自由漫遊，後輕度進展）

- **第一順位：自由漫遊。** 地圖是一座可以到處看、到處點的樂園，不是關卡。孩子沒聽任何一集，地圖依然好看、可逛、可點開每座島看看。
- **第二順位：輕度進展感。** 聽完故事會「留下痕跡」（星章多一顆、島更亮一點），但那是**溫柔的回饋**，不是任務清單。
- **明確排除：** 不做排名、不做計時、不做連續天數（streak）壓力、不做「你落後了」的語氣。進展只往上加、不倒扣、不催促。
- **家長信任基調：** 任何進展呈現都要能對家長說得通——「這只是紀錄孩子聽過什麼，不是成績、不逼他追。」

## 2. 層次（由遠到近的六層鏡頭語言）

一句話：**地圖遠景 → 島嶼聚焦 → 島嶼 sheet → 故事完成 → 星章累積 → 未來車庫圖鑑**。每往內一層，資訊更多、回饋更具體，但每一層都能獨立停下、不強迫深入。

1. **地圖遠景（map glance）** — 一眼看到整座樂園：哪些島開放、哪些在蓋、哪些即將登場。此層只給「這裡有東西、可以逛」的安全感，不塞進度數字細節。
2. **島嶼聚焦（island focus）** — 視線／相機靠近某島，木牌星章 `⭐ n/N` 與狀態 pill（開放中／建造中／即將登場／規劃中）成為主角。此層回答「這座島我聽到哪了」。
3. **島嶼 sheet（ZoneSheet）** — 點開島，看到島內故事清單、已聽打星。此層是「挑下一集」與「回味聽過的」的地方。
4. **故事完成（story complete）** — 聽完一集，`recordStoryCompleted` 記下痕跡。這是**唯一會改變進展的事件源**。
5. **星章累積（star）** — 完成回寫到島嶼星章 `⭐ n/N`，孩子下次回地圖能看到「這座島多了一顆星」。
6. **未來車庫圖鑑（future garage）** — STEM-P3：聽完／完成 craft 後解鎖車款進圖鑑。地圖是「島的完成度」，圖鑑是「車的收藏」；兩者共用同一份完成資料，呈現角度不同。

## 3. 解鎖節奏提案（柔性、對家長友善）

原則：**「解鎖」= 顯示更豐富，而非「擋住不給看」。** 任何島、任何故事一開始就都能點進去看介紹；解鎖只是把「已擁有的回饋」點亮。

- **島嶼不上鎖。** 建造中／即將登場／規劃中的島**現在就可點**（沿用 `ZONE_STATUS_META.clickable` 全為 true），只是內容是 teaser／exploreNote，不是空白牆。
- **故事不上鎖。** 每一集隨時可聽，不要求先聽 A 才能聽 B。
- **只解鎖「回饋層」：** 聽完 → 星章 +1、島嶼微亮、sheet 打星。孩子感覺到「因為我聽了，所以樂園更漂亮」。
- **島嶼「完成」的柔性里程碑：** 當某島 `n === N`，給一個安靜的小慶祝（例如木牌換成滿星表情），但**不彈窗、不擋路、不倒數下一島**。
- **未來夢想島保持「慢慢蒐集想法」語氣**（ocean 的既有 teaser），不把它變成「快去解鎖」的鉤子。
- **對家長的一句話承諾：** 「解鎖只會讓畫面更豐富，不會把內容藏起來逼孩子完成。」

## 4. 視覺層次想法（用 icon／大字，不需要新的夜景美術）

全部限制在 **transform / opacity（含 stroke-dashoffset / offset-distance）** 可表達的範圍，受 `prefers-reduced-motion` 控管，且**不新增日夜狀態、不反轉印刷地圖淺色**。

- **大字級距說故事：** 遠景時島名／星章用較大、較粗的字級當視覺錨點；靠近才顯示次要細節。以「字級與粗細對比」建立層次，而非新配色。
- **emoji／landmark 當語意 icon：** 沿用既有 `landmark`（🎡🦕🚓🌊🌲）與狀態 pill 作為一眼可辨的語意層，不需新繪圖。
- **星章是主要進展語言：** `⭐ n/N` 的「已得星 vs 待得星」用**填色 vs 淡出（opacity）**區分即可，滿星時可加一個 transform 的輕微彈跳（reduced-motion 時改為靜態滿星）。
- **「亮一點」用光暈 opacity，不用換底色：** 沿用現有淡暖光暈概念（已上線），聽越多、島的光暈 opacity 略升；**上限保守**，避免看起來像換了主題。
- **層次以「聚焦/淡出」表達：** 聚焦島時其餘島輕微降 opacity（景深感），純視覺、不改資料、不改座標。
- **無障礙：** 星章與狀態要有文字/`aria-label`（如「車車樂園，已聽 3／6 集」）；純裝飾光暈與 landmark SVG 標 `aria-hidden`。

## 5. 與 STEM-P3 車庫圖鑑的關係

- **同一份資料，兩種鏡頭：** 地圖進度看「島的完成度（n/N）」，車庫圖鑑看「車款收藏（哪些車已解鎖）」。兩者都讀 `recordStoryCompleted` 的完成清單，**不各自定義完播**。
- **地圖 → 圖鑑的自然動線（未來）：** 島嶼滿星或某集完成後，是引導到「車庫圖鑑看看你解鎖的車」的好時機，但**本輪不做入口**。
- **邊界：** 本文只負責「地圖層次語言」；車款灰階／問號／貼紙呈現、會員進階解鎖（STEM-P4）皆屬圖鑑本體，留在 STEM-P3。
- **避免重工：** 圖鑑上線時，地圖不需要重算進度；地圖與圖鑑共用 progress-store，寫入端定案後兩邊都不用改。
