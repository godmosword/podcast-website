# 小橘特快車：駕駛手感、操控回饋與進階觀察任務（2026-10-31）

來源：2026-10-31 外部意見（對照《電車でGO！！ はしろう山手線》、Train Sim World、JR EAST Train Simulator 的官方功能資料，沒有實際操作那些遊戲，也沒有 iPhone 真機）。基準 main `bd33aeb7`。

意見列了七項，建議若只做三件就做：**駕駛重量感、拖桿與狀態回饋、進階模式的提前減速**，建立「觀察 → 操作 → 感受結果 → 下次更熟練」的循環。本計畫照這個取捨，其餘另開計畫。

第二版：併入 Codex 工程審與 Opus 設計審，見文末「審查紀錄」。

級別：**L2＋UI 風險**（改物理會牽動停車預測、進站示範、自動輕煞、音效與大量 e2e；有 animation）。不生圖、不動 Protected path、不改星星。

## Goal

同一段路，孩子第二次能有意識地開得更順，而不只是停得更準；大司機、小站長要看窗外才開得好。

## Scope / Out of scope

- In：
  1. 拖桿與狀態回饋：格線容差、握把偏移、「先鬆煞車」、鍵盤一致（意見 3）。
  2. 駕駛重量感：作用漸進（先跳一段再補上）、桿槽填色看得到實際作用、聲音跟著實際作用（意見 1）。
  3. 平穩停車：停住那一刻的即時回饋＋結算一句話（意見 1、7）。
  4. 觀察任務：提前減速（沿用現有速限牌）、小站長紅燈等對向列車（意見 2）。
- Out（之後另開計畫，記 TODOS）：
  - 重玩短任務，含「練習停車」挑一站開（意見 6、原 G3）。
  - 路線地形（意見 4）。坡度會跟重量感、停車預測、慢慢看輔助全部互相影響，坡上停車還會溜；之後先做只有視覺的彎道。
  - 美術材質與空間（意見 5）。其中「離站過程」最能讓重量感被看見，E-1 上線後評估是否提前。
  - 低齡（慢慢看、小小司機）的「看窗外」樂趣：本計畫偏向 5–7 歲，下一個計畫優先補低齡。
  - iPhone 真機、車內廣播錄音（TODOS 已有）。

## Task DAG

### PR-F 拖桿與狀態回饋

- [ ] **F1 格線容差**（L1）
  - 拖曳時跨過格線再多 `max(格高 15%, 10px)` 才換檔（大司機在矮手機每格只有約 40px）。
  - 點格子、點桿槽空白處：立即跳到最近的格。
- [ ] **F2 握把偏移與多指**（L1）
  - pointerdown 在握把上：記下手指與握把中心的像素偏移，拖動時扣掉偏移再算格，不突然對齊手指。按在格子或空白處照 F1 立即換。
  - 只認主要 pointer（滑鼠左鍵、第一根手指），用 `pointerId` 追蹤拖曳；第二根手指的 pointerup 不結束拖曳；處理 `pointercancel`、離開桿面。
  - 偏移與容差寫成純函式放 `lib/games/orange-express/lever.ts`，單元測試。
- [ ] **F3 「先鬆煞車」**（L2＋UI 風險）
  - **看桿位，不看實際作用**：動力桿 >0、煞車桿 >0、速度 ≈0，持續 0.8–1.0 秒才亮；煞車桿一回 0 就收。
  - 不出現的時候：停好門亮著（該開門）、門開著（已經會抖車門）、紅燈（PR-G）、倒車、暫停。
  - 給所有規則組（小小司機最常忘記放煞車）。
  - 呈現沿用進站示範：亮煞車桿「鬆」那格，約 1Hz 脈動三下後停成靜態外框；低齡的「鬆」格是虛線，提示時改實線墨框（外框跟示範同一個黃，不用藍綠：藍綠在低齡桿面是「停」、選中格是天藍外圈，色弱分不出來）；大司機那格標 B0，桿頂的「鬆」小牌一起亮。一趟朗讀一次「先把煞車放開」，讀屏同句。同一時間只有它在動（跟出發的號誌指差鈕錯開）。減少動態只留靜態外框。
- [ ] **F4 鍵盤一致**（L1）
  - 統一成「↑↓ 永遠動力、←→ 永遠煞車」（焦點在煞車桿時 ↑ 不再動煞車）；Home／End 作用在有焦點的那根。
  - 補 `aria-keyshortcuts`；煞車桿得到焦點時讀屏說「上下鍵是動力，左右鍵是煞車」。

### PR-E-1 作用漸進

- [ ] **E1 作用漸進（物理）**（L2）
  - `RunState` 加 `tractive`（實際動力加速度）與 `braking`（實際煞車減速度）。桿位一變，作用**先跳到目標的約 35%**，剩下用一階延遲補上（沒有零反應的死區）。
  - 時間常數集中在新檔 `lib/games/orange-express/physics.ts`（D1），可全部調成 0 退回現況。煞車上升不慢於動力；慢慢看全部為 0（由輔助主導）。
  - 抽出無副作用的單步運動 `motionStep(state, dt)`（只算 tractive／braking／speed／progress／限速收回），`applyMotion` 與停車預測共用；`autoBrakeCount`、passing、phase、miss 這些副作用留在 `applyMotion`。
  - **同步與歸零規則**（每條都有單元測試）：
    - 自動輕煞：觸發當下 `tractive` 歸零（切斷動力），輕煞立即作用。
    - 緊急煞車、慢慢看輔助：立即，不延遲。
    - 速度旗收回 `BLEED`、`LOOK_CREEP` 照舊（慢慢看沒有延遲，桿位就是作用）。
    - `stopHere`、轉倒車、倒車結束、`close-doors` 換站、`createRun`：`tractive`、`braking` 歸零或設成當時桿位的目標。
    - `withHook`：有給 power／brake 就把作用直接設成目標（測試的 `jump` 不受延遲影響）；沒給就保留。
- [ ] **E2 停車預測重寫**（L2）
  - `predictStop` 改用 `motionStep` 固定步長 1/30 秒往前推，最多 600 步（20 秒）。
  - 終止條件與 reducer 同語義：在窗內速度 ≤ `stopEpsilon` → 停在該點；跨過窗尾 → 回窗尾（會開過頭）；600 步內沒停 → null（不畫三角）。
  - 「實際停點」定義為同一初始狀態、同一步長逐 tick 前進的結果；差分測試誤差 < 0.005，涵蓋窗前、窗內、窗尾、`stopEpsilon` 臨界、慢慢看爬行。
  - `coachBeat` 的假設狀態「現在拉『停』」用同一套模擬（從當下作用值開始、桿位設成 B3），不再覆寫成即時加速度。
  - 成本：4 倍 CPU 節流量影格；超標就每 3 幀算一次並沿用上次結果。
- [ ] **E3 看得到、聽得到實際作用**（L2＋UI 風險）
  - 桿槽填色：動力桿、煞車桿左邊的凹槽從底往上填色到實際作用的位置（動力橘、煞車藍綠）；握把立即到位，填色追上去。只給大司機、小站長；減少動態照常更新（是狀態不是裝飾）。不畫第二個握把。
  - 聲音：桿位一變先給一聲小小的即時音（動力「嗡」、煞車進氣「噗」），之後馬達聲、煞車嘶聲跟著 `tractive`／`braking` 漸強（`driveMix` 改吃作用值）。
  - 速度表指針的 CSS 過渡縮短或拿掉，避免雙重延遲。
  - **驗收**：從停住推 P1，大司機 300ms 內、小站長 400ms 內指針離開 0 ≥3°；改桿位的那一幀停車三角就移動。

### PR-E-2 平穩停車

- [ ] **E4 平穩判準與即時回饋**（L2）
  - 停住那一刻在 reducer 的 `stopHere` 記 `stopJerk`（停住前最後一段的減速度）。平穩＝停住時煞車 ≤ B2，或 `stopJerk` 低於門檻；對孩子就是「早一點、輕一點」。只給大司機、小站長；慢慢看由小橘自動柔停。
  - 不看「有沒有拉緊急」「有沒有開過頭」（開過頭已經算進星星，緊急煞車是保護大家的工具，用了不該拿不到稱讚）。
  - 停住當下：平穩 → 一聲輕柔的放氣「噗咻～」；頓 → 前窗點頭（≤2px、≤200ms，排在開心小橘之前）加一聲軟的「咚」。家長關掉畫面晃動或減少動態時不點頭。點頭小到不好玩，避免孩子故意猛拉。
  - 站卡不加平穩標記。
- [ ] **E5 結算一句話**（L1）
  - 放在「到家了」正下方、星星之前，當成小橘說的話，朗讀一次（照「念出來」開關）。
  - 一趟只說一件、永遠正面，依序挑第一個成立的：提前慢下來（PR-G 之後）→ 輕輕停（≥2 站，例如「輕輕停，朋友站得穩穩的」）→ 三站都剛剛好 → 跟地標打招呼 → 保底（「朋友都平安到家了」）。不寫「學會了……」，糾正留給現有的 `starMissReason`。
  - 低齡只用保底那類（「你把朋友載到了」），不提技巧。
  - 結算版面上限寫進設計文件：小橘、到家了、一句話 → 星星 → `starMissReason`（有才放）→ 站卡（色塊＋地標章）→ 至多一列計數 → 按鈕。新東西要替換，不累加。

### PR-G 觀察任務

- [ ] **G1 提前減速（沿用速限牌）**（L2）
  - 不新增牌子：大司機、小站長在進站那面速限牌（與路上降速的牌）前，提示出現後到牌子前「動力回 0 或拉了煞車」，且過牌時速度 ≤ 限速 × 1.1，就記「提前慢下來」（容得下 E1 的延遲）。來不及仍由自動輕煞協助，不扣星。
  - 做到的當下：一聲跟自動輕煞「叮叮」不同的單音輕鈴，小橘開心臉一秒。
  - 結算一句話的第一優先（E5）。
- [ ] **G2 小站長紅燈等對向列車**（L2＋UI 風險）
  - 只給小站長，不在第一站（開局推動力不走最像壞掉），也不跟示範站同一站；放有對向列車的站。
  - 狀態：每站加出發後經過秒數與號誌狀態（紅／綠），在 `createRun`、`close-doors` 換站、`withHook` 跳站時重設；暫停時不前進。這一站的對向列車改用時間觸發（關門後約 1 秒出現），不再用 `passAt`，避免雙重發車。
  - 等待要有東西看：關門、紅燈開始，對向列車的車燈就在遠處看得到，一路開過來；車尾過去的同一刻轉綠＋一聲叮。從關門到轉綠不超過 3 秒。減少動態：靜止的列車出現 → 消失 → 轉綠。
  - 紅燈時推動力：車不走；前窗右上出現紅燈小圖加看得到的「紅燈，等一下」（朗讀一次），號誌本體亮一圈；不抖車門、不亮「先鬆煞車」（F3 明確排除）。動力桿已經推著的話，轉綠後照延遲正常起步，不必再推。
  - 轉綠後才出「號誌，綠燈！」的指差確認題。前窗號誌畫紅燈狀態（現在只畫綠燈），朗讀先預告「對向列車要先過去喔」。
