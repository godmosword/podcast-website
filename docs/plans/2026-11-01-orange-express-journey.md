# 小橘特快車：減法、看得見的目標、更長的旅程（2026-11-01）

來源：2026-11-01 兒童試玩（[觀察表](../qa/orange-express-playtest/2026-11-01-pilot.md)）。一位孩子選「自己開・大司機」，**不到 2 分鐘就到家、玩起來無感**。使用者判讀三個原因：標誌太複雜（前窗速限牌、駕駛台指示燈、桿上 P／B 格位、前窗提示與按鈕）、長度不夠、目標不清楚。使用者偏好方向：**更長的路線＋沿途事件**。基準 main `c8bd287a`。

單一孩子的試跑只說明「這一組有卡點」，不推論整個年齡層。**第二次試玩排在 H3 之後**，用結果決定 H4 怎麼調、要不要往其他規則組推。

第二版：併入 Codex 工程審與 Opus 設計審，見文末「審查紀錄」。

級別：**L2＋UI 風險**（大司機桿面、駕駛台、前窗上緣、結算版面都會變；有 animation）。不生圖（前窗事件沿用幾何色塊畫法）、不動 Protected path、不改存檔格式（獎章位元與意義不變）。

## Goal

大司機一趟玩約 3 分鐘起，開局就知道「這趟要載誰、去哪裡」，路上一直看得到「到哪了、還有什麼」，每一段路都有一件看得懂、一個動作就做得到的小事；畫面上同時要看懂的符號比現在少一半以上。

## 現況（大司機）

- 一趟 3 站，每站一段 0–1 進度。巡航時每站約 7 秒，加上進站、停車、開門，整趟約 1 分鐘出頭。
- 同時出現的符號：桿上 P0–P4、B0–B4＋緊急（11 格代碼）、4 盞指示燈、速度表＋速度旗、前窗速限牌、右上提示、指差確認鈕（三題）、停車目標條、喇叭黃圈。
- 小小司機已經有一套減法（三格桿面、圖示、兩盞燈、無速限牌、無指差），試玩沒有點名它。

## Scope / Out of scope

- In：
  1. **減法（大司機）**：圖示桿面（不寫 P／B 代碼）、兩盞燈、拿掉前窗速限牌與指差確認題；降速的理由改由沿途事件說明。
  2. **看得見的目標與進度**：開局任務卡、前窗上緣的路線條、結算改成「這趟遇到的」。
  3. **更長的旅程＋沿途事件**：站與站之間插入不停車的風景段，每段一件事。
  4. **PR-G 去留**：見 D4。
- Out（記 TODOS）：
  - 慢慢看、小小司機、小站長的改動。任務卡與路線條成本低、不加複雜度，第二次試玩後優先評估給小小司機。
  - 新增站點、新地標、新場景；生圖、錄音、iPhone 真機；坡度。

## 設計

### 1. 減法（大司機）

| 現在 | 改成 | 理由 |
|---|---|---|
| 動力 P0–P4 五格，寫代碼 | 圖示桿面三格：鬆／慢／快（內部值 P0／P2／P4） | 試玩點名格位太複雜 |
| 煞車 B0–B4＋緊急六格 | 圖示四格：鬆／輕／停／緊急（內部值 B0／B2／B3／B5）。「輕」用形狀跟「停」分開（矮一半的停車柱），不只靠深淺 | 留「輕」才有平穩停車可學 |
| 4 盞燈 | 門、停車兩盞 | 速度旗燈與車內燈是資訊，不是要做的事 |
| 前窗速限牌＋速度旗顯示 | 拿掉牌子與速度旗刻度；進站速度旗與自動輕煞保留（看不到的旗，超過照樣「叮叮」輕煞） | 牌子要讀格數；事件的理由一看就懂 |
| 指差確認三題 | 拿掉（小站長保留） | 一次只做一件事 |
| 鐵橋喇叭打招呼 | 大司機拿掉（喇叭留給揮手事件與地標招呼） | 喇叭任務太多會變成一路狂按 |

- **內部 notch 值不變語意**：E-2 平穩判準仍看真實 B 值（B≤2）；E-1 時間常數不變，但最小動力從 P1（0.16）變 P2（0.28），重驗起步。F 拖桿容差照新格高重新目檢；鍵盤照格陣列步進，讀屏與 `aria-valuetext` 讀「輕」「停」等字，不讀代碼；示範強調「停」（B3）那格。
- **矮手機**：大司機套用低齡的矮手機桿高（180px，四格煞車每格約 40px），量 375×553 前窗高度前後對照（第 19 節：低齡約 189px、大司機現在約 110px）。
- **大司機跟小小司機的差別**寫進設計文件：煞車多「輕」一格、作用延遲、較窄綠區、平穩停車回饋、事件與任務。

### 2. 目標與進度

- **前窗上緣只有一條帶子**，同一時間只放一樣，優先序：停車目標條（進站後）＞事件提示（事件時）＞路線條（其他時候）。
- **路線條**（外觀是一段地圖軌道，跟停車目標條的色區明顯不同）：
  - 站點是大地標章，要接的朋友頭像從開局就站在章上，上車後移到小橘身上。
  - 事件先畫成小圓點，到了才變成圖示；經過的事件一律上色，做到的再加黃章。
  - 不寫數字、不寫距離；減少動態時小橘位置照更新、不做滑動。
- **任務卡**（開局）：每位朋友站在自己的地標旁，最後是終點的小房子；朗讀一句（「今天要去接 Bonbon、小南、馬米回家」）。**念完才收，或孩子第一次碰桿子就收**，不擋操作；收起時縮進路線條，減少動態時淡入淡出。
- **結算**（守 E-5 的版面上限，新東西替換不累加）：小橘＋「到家了」＋一句話 → 星星 → 少星原因（有才放）→ **事件章列（取代第 26 節的計數列）**：每種事件一個章、遇到幾次用下面的小圓點表示（不寫數字）；遇到的都上色，做到的墊黃章 → 一列朋友頭像 → 按鈕。一句話優先說事件（例：「小鴨都平安過鐵軌了」）。

### 3. 更長的旅程＋沿途事件

- **路線順序**（大司機）：〔風景、站、風景、風景、站、風景、風景、站〕。第一次停車提早，示範照舊在第一站。
- **資料模型**（工程審建議，風險較低）：保留 `Station`，每站加 `scenic: readonly ScenicSection[]`（站前的風景段，各有長度與事件）。`stationIndex` 仍是真正的站；新增 `sectionIndex`（等於 `scenic.length` 時在站段）。`grades`、`smoothStops`、`landmarkGreets`、`boarded`、獎章都以站為單位不變。慢慢看、小小司機、小站長的 `scenic` 為空，行為不變。
- **兩套座標**：停車、物理、預測用站段局部 0–1（不變）；前窗攝影機、事件位置、路線條用全程座標 `routeWorld`（每段起點＋局部進度 × 段長，公尺）。前窗月台、站點地標、隧道、鐵橋錨在站段；事件錨在風景段。
- **風景段**：沿用下一站的場景與巡航；沒有停車窗、停車預測、倒車、上車、示範、指差、地標招呼。進度到 1 直接進下一段，不廣播「下一站」。
- **事件**（每個事件一個動作；沒做到不扣星，小橘照樣幫忙）：
  | 事件 | 動作 | 做到的判準 | 沒做到 |
  |---|---|---|---|
  | 小鴨過鐵軌 | 慢下來 | 提示出現後放開動力或拉任何煞車（G1 的「準備」那一半，不看過點速度） | 看不到的速度旗讓自動輕煞在小鴨前慢下來，小鴨照樣過 |
  | 平交道 | 按喇叭 | 柵欄前按喇叭（真實列車是鳴笛提醒） | 照常通過 |
  | 揮手的朋友 | 按喇叭 | 經過時按喇叭 | 朋友照樣揮手 |
  | 跟小動物賽跑 | 加速 | 提示後推到「快」 | 小動物跑贏，笑著揮手 |
  - 提示至少在事件前約 3 秒出現（容得下 0.45 秒作用延遲）；做到當下小動物回應（回頭拍翅、跳一下）＋輕鈴＋小橘開心一秒。
  - 依場景換造型（幾何色塊）：田野小鴨、城市揮手的小朋友、海邊螃蟹過鐵軌與海鷗。
  - 減少動態：兩個靜態狀態（小鴨在路邊／在對面；柵欄放下／升起），平交道紅燈閃爍 ≤2Hz、減少動態時常亮。平交道「噹噹」跟自動輕煞「叮叮」分得出來。
  - 色覺：小鴨加深色描邊、站在灰色道碴上；做到／沒做到靠章的形狀（墊黃章），不只靠顏色。
- **每趟排法**：五段風景各一個事件，四種事件每種至少一次，種子由掛鉤可固定。
- **朗讀順序**：任務卡 → 下一站廣播 → 事件提示（每段最多一句）→ 地標招呼；事件提示可插在廣播前面，不跟地標招呼同時。去重 key 用 `站:段:事件 id`。
- **時間預算**（工程審重算）：風景段巡航約 6.8 秒、事件多 3–8 秒；五段約 50–75 秒；站段（含進站、停車、開門）每站約 35–40 秒。合計約 2.5–3.2 分鐘。H4 以多種排法與「新手操作」腳本（含倒車重停）量中位數與範圍，再調段長或段數。
