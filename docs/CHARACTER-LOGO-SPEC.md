# 角色 Logo 識別系統

> 35 個實例、1 套系統。硬性驗收：**32×32 可辨識**。  
> 本檔是造型／構圖／產製規範。色票見 [`CHARACTER-LOGO-COLORS.md`](./CHARACTER-LOGO-COLORS.md)。  
> 每角色資料見 [`data/character-logos.json`](../data/character-logos.json)。  
> **不取代** `public/characters/*.jpg` 定裝照；logo 是另一套小尺寸資產。

Gate 1（2026-08-19 A）：slug = `Character.id`；小南名稱用「小南」；紅爸眉線為血緣世代記號例外。

---

## 0. 這套系統在解什麼

定裝照是寫實黏土插畫，在 24–64px 會糊成一團。Logo 用**同一套幾何規則**做出 35 個可縮放識別符：靠剪影與一塊特徵，不靠紋理、編號或文字。

變數分三層，不可混：

| 層 | 35 個角色 | 內容 |
|---|---|---|
| **恆定層** | 完全一致 | 畫布、構圖、眼睛樣式、形狀預算、光源軸 |
| **識別層** | 每角色恰好一個 | 物種／機具特徵（見資料 `feature`） |
| **差異層** | 每角色一組 | 家族背景色 + 兩個 IP 基色 |

---

## 1. 複雜度預算

- 一個主導連續外輪廓，由 **6–10 個基本幾何形狀**組成。
- 最多**一個**識別特徵。挖土機只給挖斗，不要同時給履帶和駕駛艙。
- 最多兩個內部色塊（即兩個 IP 基色；背景另計）。
- 臉部只有兩眼一嘴。無眉毛、鼻孔、高光、紋理、螺絲、數字、文字。
- 黑色純剪影必須可讀（關掉色彩後仍能指認）。

### 1.1 紅爸眉線（血緣例外）

「恰好一個識別特徵」指**機具／物種特徵**。  
小紅／紅爸／小小紅／年輕紅爸是血緣家族，共用剪影模板。紅爸資料寫「尾翼 + 一道眉線」時：

- **尾翼**是機具識別特徵（與小小紅的奶嘴、年輕紅爸的小尾翼同一層）。
- **一道眉線**是世代記號，不是第二個機具特徵。允許畫在臉面上方、粗短鈍圓、併入臉部標記對比規則。
- 眉線不得變成第三色，不得做成真實眉毛細節，不得比識別特徵更大。
- 這是「臉部只有兩眼一嘴」的**唯一**允許附加記號。其他 34 位禁止眉毛。

### 1.2 沃特天線

識別特徵是「天線圓球」。桿短而粗，末端圓球必須明顯。禁止針狀天線、細線、尖端。

## 2. 造型語言

- 厚重圓潤輪廓，線寬／轉角半徑全角色一致（Pilot 後回填圓角比）。
- 禁止尖角、針狀天線、細線、銳利火焰或羽毛尖端。所有必要的尖端改為明顯鈍圓。
- 成對特徵（車燈、輪、耳、角、翼）必須兩邊都完整出現，不可裁掉。
- 多多背鰭、小怪獸角：尖端鈍圓，不得呈鋸齒或針列。

---

## 3. 構圖

刻意偏離 generic「ip-as-logo 角落冒出」規範。

- 正面微仰角。車頭本身即是臉：水箱罩＝嘴、車燈＝眼。
- **統一置中、下緣切齊**。不採用左下／右下角交替冒出——35 張 grid 會顯得雜亂。
- 剪影高度佔畫布 75–85%，上緣留白 15–25%。
- 眼睛落在畫布中線略上方。
- **兩眼間距 ÷ 眼睛半徑** 35 個角色全數一致。Pilot 鎖定前暫定 **3.0**；Pilot 定案後改本句數字，不准各角色私自改。
- 畫布不旋轉、不傾斜。
- 非車類 8 位（阿蹦、媽咪、沃特、無人機、暖暖、小怪獸、多多、萌萌）剪影可自由，但畫布、眼睛樣式、下緣切齊、色彩系統一律照舊。**眼睛樣式是把它們綁回家族的關鍵。**

### 3.1 眼睛樣式（恆定層）

- 正圓、深色實心（近 `#1A1410`），無高光、無虹膜分層、無眼白描邊。
- 嘴：一條鈍圓短弧或水箱罩形色塊，併入較深或較淺的 IP 色，不另開第三色。
- 眼睛畫在兩個 IP 色中**較亮的那塊**（車窗帶／面罩／臉面／腹部），以滿足對臉面 ≥ 5.0:1。

## 4. Flat-first 幾何 + 連續漸層微體積

- 先用平面語意色塊建構。每個 IP 色區維持單一連續形狀。
- 深度只用**一道不中斷的低頻漫射漸層**，不可用額外形狀、色塊、色帶或圖層代表光影。
- 全域光源：左上 → 右下。頭、身、附件共用同一漸層軸。
- 每個色調過渡至少橫跨主形體寬度的 50%；局部高光面積 > 主形體的 20%，禁止小面積亮點。
- 漸層必須留在原色家族內。相對該區基色：
  - OKLCH 色相漂移 ≤ 3°
  - 彩度漂移 ≤ 0.015
  - 高光亮度 +0.025～0.04
  - 陰影亮度 −0.03～0.05
  - 總峰對峰亮度變化 ≤ 0.08
- 臉部小標記（眼、嘴、紅爸眉線）保持近乎全平，不得有獨立高光或陰影。
- 背景保持視覺全平，不得有暈影、聚光或方向性漸層。
- 微體積在全解析度看得見，在 32×32 幾乎消失。

禁止：

- 寫實材質、質感貼圖、鏡面反光、輪廓光、斜角、擠出、深度遮蔽、外投影
- 完全無體積的純平塗
- 黏土／充氣／塑膠／絨毛／玩具感／強烈 3D
- 定裝照那套 claymation 語言（`CLAY_STYLE_PREFIX`）

## 5. 畫布與輸出

- 1:1 正方形，方角，不透明，edge-to-edge 背景。
- 不得有透明度、白邊、外框、卡片、圓角遮罩、App icon mask。
- 請求 **1536×1536**。若服務上限為 1254×1254 則保留原生尺寸，**不得為了湊數字而重採樣**。

落地檔名（寫進 repo 後）：

```
public/characters/logo/{slug}-512.webp
public/characters/logo/{slug}-128.webp
public/characters/logo/{slug}-32.webp
```

`slug` = `data/characters.ts` 的 `Character.id`（如 `xiao-hong`）。  
定裝照路徑不變：`public/characters/<中文檔名>.jpg`。

尚未產圖前這些 webp 不存在；驗收頁以 `status: pending` 顯示佔位框。

## 6. 色彩（摘要）

細節與七家族 OKLCH 見 [`CHARACTER-LOGO-COLORS.md`](./CHARACTER-LOGO-COLORS.md)。

### 6.1 對比不夠時怎麼調

中明度家族背景（`construction`／`speed`／`transit`／`fantasy`／`people`）與取樣 IP 常落在同一明度帶，3:1 會失敗。規則：

1. **先拉開背景與識別色的色相**（`speed`／`construction`／`fantasy` 已改；`rescue`／`transit`／`joy`／`people` 不動）。不得把家族底做成成員識別色的同色相深淺。
2. 仍不夠時**沿取樣色相調整 IP 明度**，做最小幅度推淺／推深。
3. 因眼睛是深色實心點，**優先把主體或臉面推淺**，讓眼對臉面 ≥ 5.0:1。
4. 僅 `joy`（極淺奶油底）把車身推深；次色必須是識別物色（香香遮陽棚條紋、花餐爆米花桶、噗噗豬鼻、小柔帳篷、高高輻條、嘟嘟拱頂），**禁止白／米色窗帶**。眼睛落在兩個 IP 色中較亮者。
5. 若取樣色相就是家族背景色相（藍色巴士 vs `transit`、深藍警車 vs `rescue`），放棄該色相，改用定裝照裡另一大面積色（奶油飾帶、白車門、金星）。

產圖硬閘門是**單軌加權**（primary 剪影），加上次色對背景 ≥ 3:1。臉部一律 ≥ 5.0:1 且 faceMargin ≥ +0.2。`auditEntry` 未過不得生圖。

**色票設計原則：背景色相必須遠離家族成員的識別色相，不得呼應。** 第一版把 speed／construction／fantasy 底做成成員色的同色相深淺，32px 會糊成一坨；rescue 健康是巧合（藏青離消防紅 128–175°）。

剪影門檻隨 `hueDistance(primary, 家族背景)`：

| hueDist | 適用門檻 | 含義 |
|---|---|---|
| ≥ 60° | 2.8:1 | 色相已分離，亮度可較鬆 |
| 30°–60° | 3.6:1 | 中距 |
| ＜ 30° | 4.5:1 | 同色相呼應，必須靠更大亮度差 |

`margin` = silhouette − 該筆適用門檻，仍須 ≥ +0.2（貼線視同未過）。
`faceMargin` = face − 5.0，同樣須 ≥ +0.2。

`data/character-logos.json` 的 IP hex 已依此調整；`notes` 記錄「取樣值 → 最終值 → 理由」。

### 6.2 小衝

對手，不是血緣。IP 主色必須是**黃或橘**，**不得是紅**。剪影必須明顯不同：更扁長，雙進氣口。

## 7. 撞型處理（最大失敗風險）

驗收頁五組 32px 並排必須可分辨。失敗先改本 SPEC 的恆定層／特徵佔比，不是只重抽單張。

### 7.1 賽車血緣（小紅／紅爸／小小紅／年輕紅爸）

共用同一剪影模板。只靠三件事區分：

| 角色 | 高寬比 | 擋風玻璃佔車頭 | 識別記號 |
|---|---|---|---|
| 小小紅 | 最方、最矮 | 最大（幼） | 奶嘴 |
| 小紅 | 基準 | 基準 | 單一尾翼 |
| 年輕紅爸 | 略高 | 略小 | 小尾翼 |
| 紅爸 | 最長 | 最小 | 尾翼 + 一道眉線 |

像不像是刻意的。奶嘴／眉線併入既有兩色，不開第三色。

### 7.2 小紅 vs 小衝

小衝必須真的不同剪影：更扁長、進氣口位置不同、主色黃／橘。禁止共用血緣模板。

### 7.3 消防車兄弟（圈圈／點點）

共用剪影。圈圈＝雲梯（上緣斜直線），點點＝水砲（上緣鈍圓砲管）。圈圈整體略大。

### 7.4 兩台餐車

- 香香：斜向遮陽棚，**上緣是斜線**。
- 花餐：爆米花桶，**上緣是圓形**。

剪影上緣必須明顯不同。

### 7.5 兩台計程車

知知加車頂 LiDAR 圓罩即可分開，且語意正確。計程是車頂燈箱。

### 7.6 非車類 8 位

阿蹦、媽咪、沃特、無人機、暖暖、小怪獸、多多、萌萌：剪影自由，其餘恆定層不變。

## 10. 資料契約

| 欄位 | 規則 |
|---|---|
| `slug` | 必須等於 `getCharacters()` 的 `id` |
| `name` | 分配表短名（小南＝「小南」，不是圖鑑「小南捷運」） |
| `family` | 七 key 之一 |
| `feature` | 分配表原文，Phase 1 不得自行改 |
| `ipColorPrimary` / `ipColorSecondary` | `#RRGGBB`。來自定裝照取樣，必要時依 §6.1 調整 |
| `tier` | `1` 或 `2` |
| `status` | 目前皆 `pending` |

`Character.logoFamily` / `Character.logoFeature` 由 `data/characters.ts` 從本表解析，**不**在 `characters.json` 重複一份。新增角色必須先寫 `character-logos.json`（`family` + 非空白 `feature`），否則 `requireCharacterLogo` 在模組載入時丟錯，vitest／`next build` 失敗。

## 12. 生成 prompt

- 恆定層原文：[`docs/logo-prompts/_shared.md`](./logo-prompts/_shared.md)
- 每角色可整段貼的英文：`docs/logo-prompts/{slug}.md`
- 改共用區塊後執行 `npx tsx scripts/generate-logo-prompts.ts` 重產 35 份，不要只改其中幾份恆定句。

CLI（Phase 5；**預設不呼叫 API**）：

```bash
npm run generate:character-logos -- --pilot --dry-run
npm run generate:character-logos -- --tier 1 --dry-run
npm run generate:character-logos -- --slug xiao-hong --candidates 4 --dry-run
# 准許後才拿掉 --dry-run；審 public/.logo-staging/<slug>/contact.html
npm run generate:character-logos -- --approve --slug xiao-hong --pick 2
```

- 必須指定 `--pilot`／`--tier`／`--slug`，拒絕空手生 35 張。
- **色彩驗證未過不得生圖**：產圖前對每個目標角色跑 `auditEntry`（臉部 ≥ 5.0 且 faceMargin ≥ 0.2；剪影門檻依色相距離 2.8／3.6／4.5，margin ≥ 0.2）；任一筆失敗即中止並列出違規項。`--dry-run` 不擋。
- 原生尺寸 `1024×1024`（不為湊 1536 重採樣）；落地才縮成 512／128／32 webp。
- Prompt 禁止 `CLAY_STYLE_PREFIX`；`--approve` 禁止寫入 `public/characters/*.jpg`。
- Pilot 預設 4 候選／high；Tier 1 其餘 7 位預設 2 候選；未回填 SPEC 三參數前 `--tier 2` 生圖會被擋。
- Timeout／5xx：同張最多再試 1 次。CI 不放 key。

## 13. 站內 24–32px 使用點

Logo **不取代**定裝大圖。缺 `public/characters/logo/{slug}-32.webp` 時不佔版面（`img` onError 卸下），不在 runtime 掃 `public/`。

| 位置 | 尺寸 | 行為 |
|---|---|---|
| 故事列表 `StoryCard` | 24px（吃 32.webp） | 標題下出場列；有檔才插入 |
| 單集「出場角色」`CharacterCastBar` | 32px | 名稱 chip 連 `/characters#{id}`；logo 有檔才出現在名前 |
| 角色圖鑑 `CharacterCard` 標題列 | 32px | 定裝照維持大圖；小標在名前 |
| 著色本「定裝人物」選卡 | 32px overlay | 角標疊在預覽圖上，不取代線稿／定裝預覽 |
